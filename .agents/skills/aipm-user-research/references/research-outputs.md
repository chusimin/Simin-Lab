# 用户研究输出说明

按当前任务交付计划、提纲或研究报告，可合并在一份文档中，不为结构完整生成不存在的材料。

## 研究计划

| 内容 | 要求 |
| --- | --- |
| 支持的决定 | 这次结果要帮助用户确定什么，哪些决定已经确认 |
| 研究问题 | 最会改变判断的未知，不以证明某个方案为唯一目标 |
| 已有材料 | 来源、已知发现、冲突与关键缺口 |
| 对象与选择 | 选择哪些人、怎样辨认、通过哪些实际渠道、会遗漏谁 |
| 执行方式 | 拟用访谈、观察、问卷或数据，谁实际执行，条件与限制 |
| 确认与执行状态 | 方案是否确认、哪些研究已执行、哪些仍为计划 |

对象数量与执行时长根据问题和条件确定，不填写统一默认值。没有真实材料时止于研究方案或待验证假设。

## 提纲或问卷草稿

围绕每个研究问题写主要问法与可选追问，说明要了解什么经历或取得什么数量信息。检查是否要求受访者认同方案、是否预设了原因；具体经历优先于笼统看法。

问卷选项和数量口径有实际依据，无依据处标待确定。提纲供灵活追问，不是必须逐题念完的脚本；专项量表或统计设计缺少方法时单列缺口。

## 原始材料与研究结论

| 内容 | 要求 |
| --- | --- |
| 原始材料索引 | 来源、对象或匿名标识、时间、可核对位置及记录类型，按实际权限使用 |
| 证据 | 原话或数字，保留上下文；归纳与引用分开，数字有统计口径和分母 |
| 发现与结论 | 说明材料支持什么、支持到哪些对象与条件，不外推群体比例或因果 |
| 冲突与未知 | 反例、相互矛盾的材料、解释假设和缺口，不删去不支持预设的证据 |
| 用户采用的判断 | 哪些判断已确定及其依据，确认不替代证据验证 |
| 下一步 | 是否补研究、核对哪项具体未知，或交接哪项发现与证据 |

每条研究结论应能回查原话或数字；不足时保留发现、假设或未知。未执行的研究、模拟用户回答和未核实数字不得写成已验证结论。

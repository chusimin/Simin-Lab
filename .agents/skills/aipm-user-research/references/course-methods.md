# 用户研究课件方法索引

方法来源：[需求分析与立项课件](https://w3d2-3-requirements-initiation.vercel.app/)，核对日期 2026-10-08。页码用于定位，版本变化后按标题查找。

| 定位 | 通用方法 |
| --- | --- |
| 第 24 页「去验证：用研五步」 | 定目标、选用户、设计问题、执行、整理输出；每条结论配原话或数字 |
| 第 25 页「选用户：四类，各问什么」 | 重度看深度痛点与边界、边缘看未想到场景、流失问为什么走及去了哪、潜在问为何还没来及卡在哪 |
| 第 25 页「去哪找」 | 产品内问卷、粉丝群、社区话题帖、竞品评论区、跟销售拜访；按实际可用性选渠道 |
| 第 26～27 页「The Mom Test」「坏问题 vs 好问题」 | 问生活与做过的事，不问想法好不好，不带答案提问 |
| 第 28 页「执行：定量 + 定性」 | 定量用问卷和数据回答多少、比例；定性用访谈和观察追问为什么 |

已确认的个人执行方式：从当前阶段进入，复用材料与决定；四类与渠道按问题选用，数量和时长不固定；区分证据、推断、确认与真实执行；关键判断由用户确定后撰写，仅讨论不写文件。结论范围与相邻职责是工作台设计，非课件逐字要求。

案例页仅用于理解与检验，人物、原话、数字、阈值及方案不进入通用 Skill。正式抽样、统计推断、专项问卷、复杂定性分析与因果实验等待补充方法。

# 课件方法索引

方法依据为[产品拆解与竞品分析课件](https://w3d1.vercel.app/)，相关正文核对日期为 2026-10-08。页码用于当前版本定位，版本变化后按标题查找。

| 定位 | 课件方法与本 Skill 范围 |
| --- | --- |
| 第 11 页「四层拆解图」 | 定位加用户、技术、模型、基础四层，以对应问题与产物组织拆解 |
| 第 14 页「一句话定位」 | 场景、谁、任务、结果，追问以前怎么做与替代办法；课件的 B 端三角色按已确认的实际关系按需使用 |
| 第 16～17 页「用户层构成」「用户旅程」 | 入口、输入、过程、输出、交付；信息不全、失败、改主意、不满意；标确认点 |
| 第 20 页「控制权给谁」 | 控制权安排回到目标用户与定位，不沿用业务案例中的用户类别结论 |
| 第 22～26 页「拆流程」「拆 Agent 组成」「人机分工」「为什么要人」「拆单个 Agent」 | 页面信号、岗位映射、AI 与人及确认点；成本高、主观、担责；规则、输入、任务、输出、工具与验收 |
| 第 28～29 页「两问 · 三问」「灰色问号」 | 模型是谁在想与生成、能否替换；基础是数据、算力、算法；RAG、模型选型后续专讲，本项不扩展专项方法 |
| 第 31 页「拆解图翻过来」 | 拆解产物对应产品决定；本项提供理解和证据，不直接完成当前产品方案 |
| 第 35～36 页「证据三分法」「借 AI 取证」 | 页面事实、合理推断、尚未确认；看实际产物、打开官方原文；顺序截图与旅程证据表 |
| 第 41 页「页面上看不到的，去哪查」 | 按模型、收费、数据、自有方法补查；查不到写尚未确认及查过哪里 |

用户已确认的工作台执行方式包括：真实任务优先，深度按当前问题裁剪；页面信号不能确认内部架构；实际角色按需，允许兼任；先帮助思考，复用用户决定，确认关键判断后撰写；资料不足时可交有限报告。它们不冒充课件逐字要求。

业务案例名称、数字、固定阈值、具体方案及课堂练习的固定数量不进入通用方法。价格、隐私条款和公开技术说明均保留各自证明范围，不能补出未观察的内部运行事实。

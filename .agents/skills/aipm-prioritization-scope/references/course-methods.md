# 课件方法索引

来源：[需求分析与立项课件](https://w3d2-3-requirements-initiation.vercel.app/)。正文核对日期：2026-10-08（Asia/Taipei）。页码辅助定位，版本变化后按标题查找；执行 Skill 不要求每次访问网站。

| 定位 | 课件原方法 |
| --- | --- |
| 第 62 页「Kano 分类」 | 基本型、期望型、兴奋型、反向型，以做多做少与满意度的关系理解需求 |
| 第 63 页「四象限排序」 | 价值 × 成本：高价值低成本先做，高价值高成本排进规划，低价值低成本顺手做，低价值高成本不做 |
| 第 64 页「定第一版：MVP」 | 每一版都能用；写下假设、只留必需的、定通过标准 |
| 第 65 页「MVP 范围表」 | 假设、必须做、明确不做、以后再说、怎么算验证通过；每条连回痛点，砍掉的写理由 |

用户已确认的工作台执行方式：Kano 与四象限按当前取舍选用；优先级与范围合并，支持 MVP 和已有产品迭代；复用已确定判断，用户确定关键取舍后撰写，确认与实际验证分开。这些执行方式不冒充课件固定顺序。

课件未给出通用权重、评分阈值、详细资源排期或专项成本估算方法。本版不引入其他公式，资料不足时保留缺口；案例功能、时间、比例、成本和分类结论不通用化。

# 课件方法索引

来源：[需求分析与立项课件](https://w3d2-3-requirements-initiation.vercel.app/)。正文核对日期：2026-10-08（Asia/Taipei）。页码用于定位，版本变化后按标题定位；执行 Skill 不要求每次重新访问网站。

| 当前页码与标题 | 课件方法 |
| --- | --- |
| 19「找到真用户：先画，再验」 | 分群 → 写画像 → 去验证，用真实用户核对画像 |
| 20「分群：三种分法」 | 生命周期、消费能力、购买动机；沉睡与流失要带时间；消费能力用频次 × 金额观察；动机围绕为什么买 |
| 21「写画像：写什么才有用」 | 他知道什么、他在乎什么、他在什么时候用、他因为什么卡住 |
| 24～25「去验证：用研五步」「选用户：四类」 | 确定目标、选择用户、设计问题、执行、整理输出；研究结论配原话或数字；重度、边缘、流失、潜在是研究选人时的观察类别 |

用户已确认的个人工作台执行方式：三种分法按当前任务选择适用维度，画像以四问为主体，角色关系按需要补充；先共同思考，由用户确定关注对象与决定范围后整理文档。初始假设、用户确认与研究验证分别记录；完整研究由后续工作承担。

课件的示例人物、业务场景、分类示例和固定数字不作为通用分群要求。没有交易情境时不强套消费能力或购买动机，不擅自替换为其他指标并称作课件方法。角色关系、证据状态与协作方式属于已确认的工作台设计，不是课件强制角色模板。

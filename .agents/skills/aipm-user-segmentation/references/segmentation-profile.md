# 分群与画像输出

用户确定关注对象和本次决定范围后使用；用户明确要求先整理材料时可生成标明未知的草稿。可合并为一份文档，按当前任务裁剪字段与表格，不强制生成虚构姓名、照片、人物故事或多个文件。

## 分群对比

| 字段 | 内容要求 |
| --- | --- |
| 当前问题与决定 | 产品任务；这次选研究对象、验证对象还是拟服务对象 |
| 分群依据 | 采用的课件维度、适用条件、各组辨认口径；不适用或缺方法时明确记录 |
| 关键差异 | 与当前任务、问题或约束有关的差异，不能只有人群名称 |
| 来源与状态 | 对应资料、用户陈述、分析推断、假设或未知；材料冲突分别保留 |
| 当前建议 | 建议先关注谁或先补什么证据，理由可追溯；用户的决定单独记录 |

生命周期注明行为与时间范围；消费能力注明消费频次和金额的统计范围、时间口径。数字缺失时保留未知，不借课件示例补阈值，也不由使用频次推出付费能力。

## 四问画像

为本次相关群体或角色整理四问，重点呈现会影响决定的判断。可用“问题／当前理解／来源与状态／验证缺口”表，也可用简短段落，不为填满结构补造信息。

- 他知道什么：与任务有关的知识、经验和信息。
- 他在乎什么：期望结果和实际取舍；动机假设不能写成事实。
- 他在什么时候用：触发任务的条件及相关环境。
- 他因为什么卡住：具体障碍；未知原因仍为假设。

研究结论配原话、行为记录或数字；初始画像假设写清需要什么证据。用户确认画像仅表示认可当前理解，不自动证明研究已验证它。

## 角色关系（按需）

记录实际相关角色的任务、关心的结果、已知影响关系及来源。使用者、买单者、验收者可以重合或没有独立角色；其他角色只有影响本次决定才加入。不将某角色的目标自动扩展到整个群体。

## 选择与验证记录

分别记录当前关注对象、选择范围、用户确认状态、研究验证状态与关键依据。先研究某群不等于已确定优先服务它，关注对象不自动决定 MVP。

向后续研究交接最影响决定的具体未知：需要核对哪类人的哪种经历、行为或记录，以及结果将影响哪项判断。这里不编造已完成的研究、招募、访谈、测试或收益。

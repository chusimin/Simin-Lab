# 用户分群与画像

帮助用户辨认相关人群的差异，形成有依据或明确标注假设的画像。先共同思考，由用户确定当前关注对象和决定范围，再整理文档。画像确认与研究验证分别记录。

## 进入任务

先读已有问题、用户资料与决定，明确本次是在选研究对象、验证对象还是拟服务对象。可以复用问题定义，但不强制先完成其他 Skill；已有明确选择时直接检查依据，不重复要求选人群。

可以从想法或候选人群开始，不要求先填表。材料不足时先列候选与缺口，缺少关键问题或任务时只追问会改变判断的信息；不从职业、年龄或产品名称补造用户故事。

## 分群：按任务选用课件三种分法

| 维度 | 适用与执行要求 |
| --- | --- |
| 生命周期 | 对照可辨认的使用阶段或行为；判定活跃、沉睡、流失时说明行为口径与时间范围。没有相关记录时保留未知，不套课件示例时间门槛 |
| 消费能力 | 按课件用消费频次 × 金额观察，说明消费、统计范围与时间口径。没有交易情境时可以不适用；不改成调用频次 × 算力费用，也不从高频使用推出付费能力 |
| 购买动机 | 围绕为什么购买，对照具体经历或可查资料。没有购买情境时可以不适用；缺证据时只作假设，不将课件动机示例当作完整分类 |

选择与本次问题有关的适用维度，并说明各组怎样辨认、差异如何影响任务或约束。维度可交叉，同一人的标签可随行为变化；不强制三种分法齐全或生成全部组合。

资料或课件分法不足以有效分群时，指出具体依据或方法缺口，保留候选与画像假设；不自造通用分法并称为课件要求，也不为凑表补人数、比例、阈值或评分。

## 画像：围绕四问

1. **他知道什么**：与任务有关的知识、经验和已知信息；不从学历或职业直接推出实际能力。
2. **他在乎什么**：希望得到的结果及实际取舍；动机没有依据时标为假设。
3. **他在什么时候用**：什么任务或条件触发使用，哪些环境因素影响判断；不机械追问钟点。
4. **他因为什么卡住**：实际障碍与依据，和拟增加的功能分开；原因未知时保留假设。

年龄、城市、性别、学历等只在影响任务或约束且有依据时保留。AI 使用经验、结果要求或使用限制也按相关性纳入四问，不强制补一套 AI 属性，不推断用户信任、熟练度、付费意愿或风险要求。

每个会影响决定的画像判断注明来源与状态：资料记录、用户陈述、分析推断、待验证假设或未知。用户陈述保留来源，其证据效力按具体内容判断；初始假设无需已有研究证据，研究结论则要有原话、行为记录或数字支持。单条反馈不代表整组用户，相关现象不证明因果，冲突材料保留并说明其影响。

## 角色与当前选择

使用者、买单者、验收者不同且影响当前决定时，补充各自任务、关心的结果与已知影响关系。其他角色按需要加入，同一人可兼任，不强制凑满角色。不把一人的要求自动当作全部用户的需求，也不在这里展开采购、审批或完整旅程。

按本次决定比较人群差异、已有依据和关键未知，给出先关注某群或先补研究的建议。理由要可追溯；不默认活跃、消费高或人数多的人群一定优先，不在缺信息时算出商业价值或权重。

最终关注对象由用户确定，已有自然语言确认直接复用。明确“先研究谁”“先验证谁”或“拟先服务谁”；选择研究对象不自动确定产品目标人群，也不决定需求优先级或本版范围。

## 确认与撰写

用户确定关键判断后，按[分群与画像输出](references/segmentation-profile.md)整理分群、四问画像、必要的角色关系，以及选择依据与验证缺口。结构按材料裁剪，可合并成一份文档，不强制生成多个文件。

用户明确要求先整理已有材料时，可输出标明未知的草稿，不把未确认选择写成已确认。仅讨论时不写文件；保存位置优先使用用户指定路径或当前项目既有文档位置，不创建无关项目。分别记录用户是否确认当前选择、研究是否验证关键画像。

## 完成与衔接

- 各组有可辨认依据，差异能够影响当前问题或决定；分法不适用或依据不足时明确记录。
- 画像围绕四问，关键判断有来源或明确状态，必要角色按实际分工记录。
- 关注对象及决定范围由用户确定；确认与研究验证分开。
- 下一步针对具体未知，说明需要核对哪类人的哪种经历或记录，不只写“进一步调研”。

本项不执行完整招募、访谈、问卷、需求排序、MVP、商业论证、旅程、原型或 PRD。画像假设与验证缺口交给用户研究；研究结果可反过来修正分群。重度、边缘、潜在、流失等研究招募类别不自动等于产品目标人群。后续 Skill 未接入时说明工作职责，不声称已调用或完成。

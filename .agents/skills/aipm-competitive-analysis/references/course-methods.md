# 课件方法索引

方法依据为[需求分析与立项课件](https://w3d2-3-requirements-initiation.vercel.app/)第 53～58 页，分层与取证复用[产品拆解与竞品分析课件](https://w3d1.vercel.app/)。相关正文核对日期为 2026-10-08；版本变化后按标题重新定位。

| 定位 | 课件方法与本 Skill 范围 |
| --- | --- |
| 需求课第 53 页「定目的」 | 0～1 看市场格局空白，1～N 看功能差评，对手出招看原因与用户是否买账，定价看价格与成本 |
| 第 54 页「找竞品：四类」 | 直接、间接、替代、潜在，依据同一需求选择相关对象 |
| 第 55 页「定维度」 | 横向比较市场，及定位、用户旅程与完整产物、技术流程分工与单个 Agent、模型、基础数据与成本 |
| 第 56 页「收信息」 | 主流程使用、评论、社区、官网财报定价、融资招聘、第三方；渠道获取按实际权限，不要求必须购买 |
| 第 57 页「让 AI 论证你会失败」 | 每个数据标来源，给出竞品成功而自己失败的最强论证；假设不成为事实 |
| 第 58 页「差异化方向」 | 从用户、需求、场景寻找更垂直、更深、更专的方向；核查 X 用户、Y 重要结果、Z 对手限制 |
| 拆解课第 11、16～17、22～28 页 | 定位和四层，以真实任务、旅程、分工、模型和基础层组织比较；页面信号不直接证明内部实现 |
| 第 35～36、41 页 | 页面事实、合理推断、尚未确认；核查实际产物与官方原文；查不到说明已查渠道和未知 |

用户已确认的工作台执行方式包括：围绕一项决定，竞品类型与维度按目的裁剪；先确定可比任务和条件，不能对齐时保留限制；先帮助思考，用户确定方向后写文档；差异化允许未知、附条件或暂缓，不要求确定说出竞品做不了。它们不冒充课件逐字要求。

课件未提供统一市场估算、竞品评分权重、定价计算或完整差异化实验方法，本项不自行补成通用算法。业务案例名称、数字、固定阈值、人物与具体方案不进入通用方法。

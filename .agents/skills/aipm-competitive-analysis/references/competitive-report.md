# 竞品分析文档与证据要求

用户确定关键判断后读取，按目的和已有材料裁剪，可用一份文档承载。证据不足时允许附条件结论、有限比较或暂缓，不强制评分、排名与赢家。

## 文档内容

| 内容 | 要写清什么 |
| --- | --- |
| 目的与范围 | 当前支持哪项决定，已有用户方向，比较对象与纳入理由 |
| 任务与条件 | 用户、任务、输入、完成标准、日期、版本、账户或套餐、模型、权限；不一致条件及其影响 |
| 分层比较 | 与决定相关的市场、定位、旅程及完整产物、流程分工、模型、数据与成本；差异为什么重要 |
| 证据与限制 | 关键数据和判断的来源、时间、统计或观察范围、状态；未知与冲突 |
| 反方论证（有当前方向时） | 竞品可能成功、当前方向可能失败的最强理由，分开依据与假设 |
| 差异化候选 | X 用户、Y 重要结果、Z 对手限制、自身实现依据及尚未证明的部分 |
| 用户决定与交接 | 采用哪个判断或方向、确认状态、保留风险、具体补证据与验证问题 |

目标用户与同一任务不一致时，说明哪些比较仍有用，不把不同输入、套餐或完成标准下的表现直接排名。差异化选择不自动成为需求优先级、版本范围、立项结果或最终定价。

## 证据表

| 字段 | 内容要求 |
| --- | --- |
| 对象与判断 | 哪个产品、替代办法或候选方向，支持什么决定 |
| 来源 | 使用记录、完整输出物、截图编号、官方链接、评论原文或第三方资料 |
| 条件与范围 | 日期、版本、套餐、输入、模型或统计口径等会影响结论的条件 |
| 状态与证明范围 | 页面事实、合理推断、尚未确认；公开声明、他人观察和估计按各自范围说明 |
| 冲突或缺口 | 结论不能覆盖什么、冲突发生在哪些条件下 |
| 下一步 | 验证哪类用户的重要结果、对手哪项具体能力或自身哪项实现依据 |

少量评论不推导普遍需求，一次表现不证明稳定能力。未找到功能写未找到证据，不能写竞品永远做不了；价格不写成成本，页面角色和模型选择不写成后台实现事实。

## 交付前检查

- 分析支持明确决定，对象纳入理由与用户需求有关。
- 比较任务与条件清楚，范围不足处有明确限制。
- 每个关键数据和判断可追溯，公开声明、观察、推断与未知得到区分。
- 反方论证没有制造事实，差异化 X、Y、Z 与自身能力保留证据状态。
- 用户决定、风险与具体验证动作得到保留，未自动推进其他工作。

# 课件方法索引

方法来源：[需求分析与立项课件](https://w3d2-3-requirements-initiation.vercel.app/)。正文核对日期：2026-10-08。页码辅助定位；版本变化后按标题定位。执行本 Skill 不要求每次重新访问课程网站。

| 当前页码与标题 | 方法要求 |
| --- | --- |
| 10～11「把问题说清」「还原场景」 | 明确谁、何时何地、在做什么、卡在哪、现在怎么凑合 |
| 12「分开问题和方案」 | 听到功能名，追问“有了它，你想解决什么？”，再改写为问题 |
| 14「问三次为什么」 | 每次只追一层，对照做过的事，停在能动手的一层 |
| 16「该不该用 AI」 | 重复性高、标准化程度高、人力瓶颈明显；三个都占才用 AI；再问改流程能否更便宜 |
| 17「问题定义卡」 | 谁、场景、问题、现有办法、代价、一句话定义 |

个人工作台采用共同思考、用户确定关键判断后撰写的协作方式。按已提供信息选择追问、保留证据状态与后续职责，是执行方式；不改变 AI 三条件同时满足的课件要求。业务案例不属于通用方法内容。

# 需求整理与管理课件方法索引

方法来源：[需求分析与立项课件](https://w3d2-3-requirements-initiation.vercel.app/)，核对日期 2026-10-08。页码用于定位，版本变化后按标题查找。

| 定位 | 通用方法 |
| --- | --- |
| 第 42 页「拆动作：从结论到动作」 | 用户是谁、需求是什么、什么场景、遇到什么问题、推出动作；动作先进池，不排序 |
| 第 43 页「需求池」 | 能力项名称、业务痛点和目标、建设方向、需求来源、当前状态、需求描述与 PRD 链接 |
| 第 43 页字段说明 | 建设方向为增长、转化、留存、体验；需求来源为业务提需、产品自驱 |
| 第 45 页「跟着状态走」 | 立项、调研、设计、开发、测试、已上线、迭代、下线；进池门槛为说得清重要性 |

已确认的个人执行方式：候选、入池、验证、立项与排期分开；主结构沿用六字段，来源分类与原始材料出处分开；状态按实际资料与项目口径，不强制单向必经；复用现有维护源及已确认决定，关键判断确定后撰写，仅讨论不写文件。

出处追踪、重复项处理和状态依据为工作台设计，非课件逐字要求。案例名称、原话、数字、日期、阈值与方案不进入通用 Skill；复杂变更协同、工具配置及通用合并规则等待补充方法。

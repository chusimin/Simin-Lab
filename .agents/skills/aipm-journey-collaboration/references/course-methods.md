# 课件方法索引

来源：[产品拆解与竞品分析课件](https://w3d1.vercel.app/)。正文核对日期：2026-10-08（Asia/Taipei）。页码辅助定位，版本变化后按标题查找；执行 Skill 不要求每次访问网站。

| 定位 | 课件原方法 |
| --- | --- |
| 第 11、16～17 页「四层拆解图」「用户层由什么构成」「用户旅程」 | 入口、输入、过程、输出、交付；信息不全、失败、中途改主意、不满意；标确认点 |
| 第 20 页「控制权给谁」 | 控制权选择回到定位和目标用户 |
| 第 23～24 页「拆 Agent 组成」「人机分工表」 | 先想人的岗位与步骤，再逐步对照 AI／人并标确认点；分工表说明为什么要人 |
| 第 25 页「为什么要人」 | 成本高、主观、担责；便宜、可撤回、能局部改的步骤不应例行停下询问 |
| 第 26、31 页「拆单个 Agent」「四层拆解图翻过来读」 | 输入、任务、输出、工具、规则和验收；设计交互、确认点、失败兜底、流程与人机分工 |
| 第 35 页「证据三分法」 | 页面事实、合理推断、尚未确认；完成核对实际产物，官方说法核对来源 |

用户已确认的工作台执行方式：按任务设计旅程与责任，按课件三种原因设置确认点；已有判断和授权直接复用；当前观察与拟议设计分开。此项聚焦用户流程、控制权和异常，完整 AI 能力细化由相应 Skill 承接，确认后撰写。

课件案例不规定所有新手／专业用户的偏好、岗位数量、Agent 架构或业务失败处理。专项失败策略、人工时限和可靠性门槛未覆盖时保持缺口，不复制案例填满。

# Simin · 参考图设计提取与界面规范

本规范用于完整交互原型的视觉实现。项目、文档、搜索、模板、回收站、设置及其交互沿用当前原型，内容和状态仍使用原型示例数据。

## 1. 从参考图提取的设计语言

参考为用户提供的 1200 × 900 截图。核心特征是双层导航、浅灰内容画布、居中欢迎区、紧凑卡片、胶囊操作和柔和浮层。阅读重心落在中间一组内容上，背景留白围绕内容组织。

| 区域 | 截图观察 | Simin 对应方式 |
| --- | --- | --- |
| 外框 | 左上约 (52,58)，宽约 1095、高约 784，圆角约 28 | 灰色外部画布，白色圆角应用容器 |
| 一级导航 | 约 56px 的窄图标栏，选中项为深色圆形 | 工作台、文档、模板、回收站四个图标入口，底部设置 |
| 二级导航 | 约 190px 白色侧栏，行高约 32px | 项目列表或当前项目的文档列表 |
| 顶部 | 约 58px 白色工具栏，小字标题与紧凑按钮 | 面包屑、项目操作、搜索 |
| 欢迎区 | 42px 蓝色球体，约 25px 正常字重标题 | 小型蓝色圆形标志配 Simin 四角星，24px 中文问候 |
| 卡片组 | 三张约 188 × 120px 卡片，间隔约 15px | 三列紧凑项目卡；最近使用的项目用深色突出 |
| 快捷操作 | 40px 高胶囊按钮，浅色小图标与柔和阴影 | 新建、全部文档、模板、搜索四个快捷入口 |
| 输入框 | 约 638 × 88px，圆角约 25px，工具按钮为胶囊 | 对话中的浮起式输入框，22px 圆角与胶囊发送按钮 |

保留参考图的比例、密度与层次，内容采用 Simin 的项目和文件体系。桌面标题栏及中文排版按使用场景适配。

## 3. 字体与信息密度

系统字体：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`。不依赖在线字体。

| 用途 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 首页问候、空状态标题 | 24px | 400 | 1.4 |
| 页面、文档标题 | 22px / 25px | 500 | 1.5 |
| 卡片名称 | 14px | 500 | 1.6 |
| 界面与文档正文 | 12px / 13px | 400 | 1.8 / 1.95 |
| 侧栏行与按钮 | 11px / 12px | 400 | 1.6 |
| 分组、时间、辅助信息 | 10px / 11px | 400 | 1.7 |

首页标题居中，正常字重，无渐变、投影或装饰字体。文档保留独立阅读层级。列表文字和图标始终沿同一轴对齐。

## 4. 组件规范

一级导航按钮 34–38px、圆形；图标 16px，选中用深色圆底白色图标。二级导航行高 32px，浅色圆形项目标记。主按钮 32–36px、胶囊圆角，白色次按钮使用双层轻阴影；悬停加深文字与边框，按下下移 1px，焦点为蓝紫色轮廓，禁用降低透明度且不接受操作。

首页项目入口采用用户新增参考图中的黑色圆角底座、半透明文件袋和错落纸片。图形约 168px 见方、23px 圆角；袋口呈 V 形，白色前袋透明度约 68%，局部 3px 模糊和细描边体现材质。图形下方不放标题、说明、日期或进度；空项目名称放在前袋，完整名称和计数通过提示与无障碍标签提供。

纸片来自 `project.docs`，最多显示三张。第一张对应第一篇真实文档，同时显示项目标题、文档名和内容片段；其余纸片显示实际文档标题和内容。项目封面不额外增加一张纸片。零篇文档时不渲染纸片，一篇时只放一张，两篇时只放两张；三篇及以上露出三张，文件袋始终显示实际总数。回收站中的文档不计入项目。列表模式纵向排列同样的 168px 文件夹，不添加并排说明。

输入框白底、22px 圆角、轻边框与阴影，工具项胶囊化。文档与对话各有独立白色表面，中间以 10px 间距区分。模态圆角 20px，标题 18px，操作和差异区域沿用同一套样式。默认、悬停、按下、键盘焦点、禁用状态均保持可区分。

## 5. 布局与空间

桌面外部留白 36px，应用容器 28px 圆角。模拟标题栏 28px，一级导航 58px，二级侧栏 194px，顶部工具栏 54px。内容画布与外框之间保留 10px 间距；首页内容组最大宽度 770px，文件夹组最大宽度 544px、间距 20px，欢迎区到文件夹组约 36px，文件夹到快捷操作约 20px。间距梯度使用 4/8/10/12/16/20/24/32/36px。

文档页布局为 58px 图标栏 + 194px 项目侧栏 + 弹性文档 + 360–420px 对话。概览、模板、设置使用灰色画布上的白色内容组件。所有页面沿用同一导航、颜色、圆角和按钮体系。

## 6. 层次与阴影

| 对象 | 层次 |
| --- | --- |
| 主画布 | 无阴影，浅灰背景 |
| 列表与文档 | 白色表面，1px 轻边框 |
| 白色胶囊按钮 | `0 1px 3px rgba(var(--ink-rgb), .04), 0 4px 12px rgba(var(--ink-rgb), .025)` |
| 输入框与模态 | 薄边框加扩散阴影 |
| 首页文件夹 | 黑色底座、白色纸片与半透明前袋形成局部层次 |

减少贯穿页面的分割线，层次主要来自表面色、局部边框与间距。没有大面积毛玻璃。

## 7. 动效与交互

保留已经通过体验验证的行为：创建与重名提示、讨论、文档预览、确认写入、修改审阅、搜索跳转、模板草稿、回收站恢复、偏好保存、失败重试、停止和进度恢复。此次变更只调整展示结构与样式。

采用 L1 轻交互动效，无额外依赖。常规过渡 140–180ms，入场使用 opacity 与 4px 位移。文件夹悬停时，纸片在 220ms 内抬起 4–8px、略微展开。触屏不触发悬停动效，系统要求减少动态效果时纸片保持原位。浮层保持 Escape 关闭与焦点循环，输入保持原来的发送快捷键。

## 8. 设计约束

- 首页内容集中成组，周围留白服务于视觉重心。
- 使用小图标、轻标签与正常字重，保持紧凑和可读。
- 一项目一主线，模板只提供讨论起点。
- 深色用于主要动作与文件夹底座，首页只展示文件夹图形。
- 保存、待确认、修改前后保持清楚的状态反馈。
- 不把卡片做成横向铺满的大面板。
- 文件夹纸片和数量必须对应当前项目真实文档，空项目不填装饰纸片。
- 不引入多助手、会员或参考图中的集成入口。
- 不增加重阴影、大面积渐变、装饰性背景纹理。
- 不因视觉修改重置用户已经输入的演示内容。

## 9. 响应式与检查

1180px 以下二级侧栏收至 180px，文档和对话适当收窄。900px 以下继续保留文档/对话切换。600px 以下图标栏与固定侧栏折叠成导航抽屉，文件夹组为两列、最大宽度 356px，欢迎区减小上方留白，浮层留 16px 外边距。主要触摸操作至少 44px，长名称换行或省略，无横向溢出。

视觉检查覆盖首页、空项目、项目概览、文档与对话、模板、设置和确认浮层；交互回归覆盖创建、文档确认、搜索与窄屏导航。截图等待入场动效完成后采集。

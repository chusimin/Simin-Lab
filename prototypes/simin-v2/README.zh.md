# Simin 交互原型

[English](README.md) | 中文

## 概述

这是独立的设计原型，使用浏览器本地的示例项目、文档、对话、回收站和偏好，未接入 Agent 或真实项目文件。桌面应用请参阅[平台说明](../../README.md)。

## 打开与体验

直接打开仓库根目录的 `Simin工作台-完整原型.html`。它内嵌脚本与样式，不需要外部资源。本目录的 `index.html`、`style.css`、`app.js` 是维护源，[DESIGN.md](DESIGN.md) 记录视觉方向。

通过右上角的页面导览浏览页面与状态，或启动核心流程体验。演示状态保存在浏览器 localStorage 的 `simin.prototype.v2` 中。

| 入口 | 演示交互 |
|---|---|
| 首页 | 新建项目、网格与列表切换、恢复进度 |
| 项目 | 讨论、停止、重试、审阅拟保存内容 |
| 文档 | 阅读、源码、复制、引用、专注模式 |
| 保存审阅 | 确认或取消新建、修改 |
| 搜索 | 查找项目、文档与示例对话 |
| 讨论起点 | 预览提示模板并带入草稿 |
| 回收站 | 恢复文档或确认永久删除 |
| 设置 | 调整发送方式、进度恢复与动态效果 |

助手回复均为固定演示，编辑和保存只修改原型的浏览器数据。

## 键盘与窗口

Cmd/Ctrl+K 打开搜索，上下键选择结果，Enter 打开。Escape 关闭弹窗或退出专注阅读。默认 Enter 发送、Shift+Enter 换行，设置可以切换为 Cmd/Ctrl+Enter 发送。窄窗口提供导航及文档、对话切换。

原型采用黑白主色、少量点缀色、半透明文件夹入口和黑色主要操作。桌面实现会在这个设计参考上独立迭代。
